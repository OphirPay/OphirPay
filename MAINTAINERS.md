| DevOps | `@OphirPay/devops` | CI/CD, Docker, Kubernetes, Helm, scripts |
| Documentation | `@OphirPay/docs` | `*.md`, `docs/` |
| Security | `@OphirPay/backend` | `SECURITY.md`, auth, crypto, rate limiting |
