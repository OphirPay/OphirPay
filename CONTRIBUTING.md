## Dependency Updates

We use Dependabot to keep our dependencies up to date.  
- **npm**: updates are grouped by minor/patch and run weekly.  
- **Cargo**: updates for the `contracts/ophirpay` and `contracts/emitter` directories are grouped similarly.  
- **GitHub Actions**: updates for workflow files are also grouped.  

All Dependabot PRs are automatically labeled and assigned to the DevOps team.  
If you encounter a PR that you believe should be excluded, please comment on the PR or open an issue.
