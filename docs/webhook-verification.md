# Webhook Signature Verification Guide

OphirPay cryptographically signs all outgoing webhook events using an HMAC-SHA256 signature. This allows your backend receiver to verify that incoming payloads are authentically generated by OphirPay, have not been tampered with in transit, and are not replay attacks.

---

## 1. Webhook Delivery Headers

Every HTTP POST webhook request sent by OphirPay includes the following headers:

| Header | Description | Example |
|---|---|---|
| X-OphirPay-Signature | Hexadecimal HMAC-SHA256 signature computed over the canonical payload | 5d41402abc4b2a76b9719d911017c592... |
| X-OphirPay-Event | Event type identifier string | payment.succeeded, atch.completed |
| Content-Type | MIME type | pplication/json |

---

## 2. Canonicalization & Signature Scheme

OphirPay uses deterministic canonicalization to ensure identical serialization across environments:

1. The JSON body contains the fields event, 	imestamp, data, and optionally signature.
2. **Canonical representation**: The payload is canonicalized by setting the signature field to an empty string " (JSON.stringify({ ...payload, signature:  })).
3. **HMAC Calculation**: An HMAC-SHA256 is computed over this canonical UTF-8 JSON string using your webhook endpoint's secret key:
 \text{Signature} = \text{HMAC-SHA256}(\text{Secret}, \text{CanonicalJSON})
4. The resulting hex digest is sent in the X-OphirPay-Signature header and embedded inside the JSON body.

---

## 3. Security Requirements

### A. Timing-Safe Comparison
To prevent timing-based side-channel attacks, always compare HMAC signatures using a constant-time comparison utility (e.g. crypto.timingSafeEqual in Node.js or hmac.compare_digest in Python) rather than standard string equality (=== / ==).

### B. Replay Attack Prevention
Always verify the imestamp field embedded in the payload. Compare the ISO 8601 timestamp against the current server time and reject any webhook whose timestamp is older than 300 seconds (5 minutes) or in the distant future.

## 4. Reference Implementations

### Node.js / TypeScript Reference

` ypescript
import crypto from crypto;

export interface WebhookPayload {
 event: string;
 timestamp: string;
 data: Record<string, unknown>;
 signature?: string;
}

export function verifyWebhookSignature(
 rawBody: string,
 signatureHeader: string,
 secret: string,
 toleranceSeconds = 300
): { valid: boolean; reason?: string } {
 if (!signatureHeader || !secret) {
 return { valid: false, reason: Missing signature or secret };
 }

 let payload: WebhookPayload;
 try {
 payload = JSON.parse(rawBody);
 } catch {
 return { valid: false, reason: Invalid JSON };
 }

 // 1. Replay attack check
 const eventTime = new Date(payload.timestamp).getTime();
 const currentTime = Date.now();
 if (isNaN(eventTime) || Math.abs(currentTime - eventTime) > toleranceSeconds * 1000) {
 return { valid: false, reason: Timestamp outside tolerance window };
 }

 // 2. Canonicalize payload
 const canonical = JSON.stringify({
 event: payload.event,
 timestamp: payload.timestamp,
 data: payload.data,
 signature: ,
 });

 // 3. Compute HMAC-SHA256
 const expectedSignature = crypto
 .createHmac(sha256, secret)
 .update(canonical)
 .digest(hex);

 // 4. Timing-safe comparison
 const sigBuf = Buffer.from(signatureHeader, utf-8);
 const expBuf = Buffer.from(expectedSignature, utf-8);

 if (sigBuf.length !== expBuf.length || !crypto.timingSafeEqual(sigBuf, expBuf)) {
 return { valid: false, reason: Signature mismatch };
 }

 return { valid: true };
}
`

### Go Reference

`go
package webhook

import (
 crypto/hmac
 crypto/sha256
 encoding/hex
 encoding/json
 errors
 math
 time
)

type Payload struct {
 Event string json:event
 Timestamp string json:timestamp
 Data map[string]interface{} json:data
 Signature string json:signature
}

func VerifyWebhookSignature(rawBody []byte, signatureHeader string, secret string, tolerance time.Duration) (bool, error) {
 var payload Payload
 if err := json.Unmarshal(rawBody, &payload); err != nil {
 return false, err
 }

 eventTime, err := time.Parse(time.RFC3339, payload.Timestamp)
 if err != nil {
 return false, err
 }

 if math.Abs(time.Since(eventTime).Seconds()) > tolerance.Seconds() {
 return false, errors.New(timestamp outside tolerance window)
 }

 payload.Signature = 
 canonical, err := json.Marshal(payload)
 if err != nil {
 return false, err
 }

 mac := hmac.New(sha256.New, []byte(secret))
 mac.Write(canonical)
 expectedSig := hex.EncodeToString(mac.Sum(nil))

 if !hmac.Equal([]byte(signatureHeader), []byte(expectedSig)) {
 return false, errors.New(signature mismatch)
 }

 return true, nil
}
